wasm-hybrid-wasi

This example compiles the native Rust nostr crate (which includes the C secp256k1 library) to wasm32-wasip1 and runs it in the browser via a WASI shim.

Prerequisites

rustup target add wasm32-wasip1
# Install wasi-sdk (required for C compilation):
# macOS: download from https://github.com/WebAssembly/wasi-sdk/releases
# Linux: apt install wasi-sdk  (or download release tarball)
# Then set: export WASI_SDK_PATH=/path/to/wasi-sdk

Build

cd examples/wasm-hybrid-wasi
cargo build --target wasm32-wasip1 --release

Run (CLI)

wasmtime target/wasm32-wasip1/release/wasm-hybrid-wasi.wasm
# or
wasmer target/wasm32-wasip1/release/wasm-hybrid-wasi.wasm

Run (Browser)

Open the browser console to see output.
